# Banking Fraud Detection & Risk Analytics

## Project Overview

This project uses machine learning to detect potentially fraudulent banking transactions and assign a risk score to each transaction.

## Objectives

- Analyze banking transaction data
- Perform exploratory data analysis
- Preprocess transaction data
- Engineer fraud-related features
- Train machine learning models
- Evaluate model performance
- Predict fraud probability
- Generate transaction risk scores
- Provide an interactive Streamlit dashboard

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
- Joblib

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
